# Sound picks

Choose only sounds that reinforce a visible action. Reuse a few at restrained
levels; silence between actions is useful. Copy selected files into the run.
No library scan or spectral analysis is needed.

| File | Use | Original Kenney asset |
|---|---|---|
| `soft-impact.ogg` | Evidence row landing | `impact/impactSoft_medium_001.ogg` |
| `transition.ogg` | One major handoff | `impact/impactSoft_heavy_002.ogg` |
| `payoff.ogg` | Important conclusion, sparingly | `impact/impactBell_heavy_000.ogg` |
| `accent.ogg` | Small reveal | `interface/bong_001.ogg` |
| `click.ogg` | Deliberate simulated click | `interface/click_003.ogg` |
| `switch.ogg` | Toggle or state change | `interface/switch_007.ogg` |
| `slide.ogg` | Sliding object | `casino/card-slide-1.ogg` |
| `place.ogg` | Object placement, sparingly | `casino/card-place-1.ogg` |
| `keypress.wav` | An actual typing demonstration | `keyboard/keypress-001.wav` |

Source: [Kenney](https://kenney.nl/), CC0. These are production assets, not
style references. Never add a click for every subtitle word.
